## Result and evidence

The same post-Bowfa fixture now has nearer tormented/occult pursuits, a separately justified CoX activity and a long-term Shadow preview. Shadow's larger supported damage does not override its remaining acquisition class. Ownership or preparation unknowns keep an item in Check first/Plan ahead; a small or zero supported gain is deferred. Every relevant reviewed outcome remains in Browse. No goal or filled-card quota is required.

[Six complete synthetic profiles](r15-scenarios.md) pin observed item IDs, levels, fact/quantity scope, explicit negative planning confirmations, full reference slots/context, comparisons, routes and ordering reason codes. They include post-Bowfa, tbow/no Shadow, Shadow owner, several missing CoX families, only rare R1 magic value remaining and nearer opportunities with owned horn. Counterfactual tests cover ownership, unknown unlocks, preparation, components, skips and invalid probability support. Unsupported future combat names appear only in pure ranker fixtures, not runtime promotions. Existing midgame/declined-CG, advanced-alternative, reference and lifecycle regressions still run.

CoX groups Ancestral pieces into **one family**. Rigour/Augury count only when relevant wield/skill conditions hold and both unlock and scroll absence are confirmed. Owning scrolls/pieces shrinks the useful set; unknown unlocks are explicitly excluded from confirmed votes. Gains and drop probabilities are never added. Owned shard/horn/icon/vestige stages do not create votes for fresh reward acquisition. One ordinary useful reward is a single route, not automatically a long-term grind or shared opportunity.

Only E1 next-shard odds are shipped. The estimator uses the reviewed demonic-gorilla source [revision 15362958](https://oldschool.runescape.wiki/w/Demonic_gorilla?oldid=15362958), already reviewed in RESEARCH/R1. For future independent eligible kills at p=1/300: mean 300, median 208, P90 690, P10 32. Hand checks verify minimal integer quantiles. A user scenario of 40 kills/hour gives mean 7.5 h, median 5.2 h, P90 17.3 h; 10% take longer. This pace is synthetic and unmeasured. Default hours are unavailable. A 30–50 range gives mean sensitivity 6–10 h, not a confidence interval. Past dry kills do not change the future fixed-rate distribution.

The estimate is **next shard only**. Owned shard/uncut/gem/bracelet removes that drop stage; uncertain alternatives require a targeted check. Access, onyx, crafting/training, assembly and supplying the activity are excluded, so this is never a full bracelet ETA. P=0/1, bad probabilities, invalid/unknown/mismatched pacing and known-invalid support are tested. Raid personal allocation, current CoX mode/points/weights, ToA, Nex contribution, stateful vestiges and challenge success/time remain unmodelled: no old 69-total CoX weighting or conditional unique weight becomes a per-raid rate. Other valid value/path evidence remains available when odds are withdrawn.

## Contracts and safeguards

Schema 7 adds reviewed outcome role/family/context keys, route-specific effort/mode/burden/tail metadata and owned-component variants, acquisition specs and independently evaluated legacy activity benefits. Evidence links have bidirectional `acquisitions`, `efforts` and `rewards` dependencies. Unknown references, bad probability/scope data and path cycles fail closed. Existing justified resource/depth guards remain; no item/boss/count quota is added. A Zaryte recipe DAG exposes its existing horn/ACB/shard work and reviewed 90 Fletching separately.

The pure ranker admits categories before sorting. Immediate ordering considers readiness/remaining burden before value, then optional interest, explicit reviewed context coverage, confidence, a fixed comparison bucket and stable IDs. Numeric tie-breaking requires the same role, target, baseline and model assumptions. Dominance requires matched evidence plus explicit remaining-step inclusion or disjoint expected-work ranges, no worse tail/coordination/upkeep and no competing allocations. Overlapping/unknown work and different targets remain trade-offs. Qualitative specialist value stays separate from unavailable DPS. No DPS/hour score, quantile sum, combined reward gain or RNG completion bar exists.

Pace scenarios and reference setups stay in memory. Numeric/range input is optional, has explicit cycle/overhead scope and can be cleared. Queued input checks character generation, snapshot and revision; lifecycle/account/profile transitions clear it. Existing serial local preference IO/migration remains unchanged. Preference schema 2 keeps all existing stable keys and adds only two explicit scroll ownership labels; raw observations, pace and reference data are not saved. Delayed image loads can update only retired labels after a view changes.
